# 手动研究：判断框架与证据

先核对 `refresh` 的每项状态、最新 K 线结束时间和数据质量；缓存不等于实时，节假日未核实时不声称盘中。对每个结论给出观测数据、推断、反证和失效条件，不预测精确点位或概率。`context` 缺少历史时必须保留不足，不自行补齐。

## 固定数值口径

`returns_pct` 为最后一根收盘价相对 1、4、20 根之前收盘价的变化；不足时为 null。`moving_averages` 为 5、20 根简单收盘均线、最新收盘相对均线的百分比及均线相对上一根均线变化百分比，需至少 N+1 根。`range_amplitude_20_pct` 为最近 20 根最高价与最低价的比值减一（不是 ATR、收益波动率或换手率），不足 20 根为空。按 15、60 和日线分别计算；日线不复权，跨除权不能直接比较。`stock_relative_return_pp` 和板块 `relative_return_pp` 只在两根 K 线时间完全对齐时为个股相对指数或板块的单根收益差（百分点），不代表因果。

`same_time_amount_ratio` 是最新成交额除以此前同时间成交额中位数，样本数单独报告；样本过少不确认量能异常，不与换手率或资金净流入混同。历史数据不足时禁止用更少周期假称 20 根指标。周末、休市和停牌造成的缺口必须说明。

## 分析顺序与条件

1. **市场与板块**：先分别列指数及相关板块的方向、可比较的相对收益和数据时点；未配置映射则无法判断板块共振。`hotspots` 为数据源板块涨幅榜，覆盖范围及数据延迟待核验，且历史快照缺失时不能判断持续性；不同板块有重复成分，排名变化不是资金流向。
2. **多周期趋势**：比较日线、60 分钟和 15 分钟收益、均线位置及斜率；每个周期分别记录最近收盘是否高于 5 根均线、5 根均线斜率是否为正、4 根收益是否为正：三项均满足可标记“偏强观察”，三项均为负可标记“偏弱观察”，其余为“混合或不足”。这只是描述标签，不是买卖信号；日线、60 分钟和 15 分钟出现不同标签时必须列出冲突。均线滞后、震荡中容易反复交叉。
3. **区间与成交额**：将收盘越过前序区间作为突破候选；下一根已闭合 K 线收盘仍在前序上沿之上可记为一次保持，重新收回区间可记为突破候选失效；下破时对称处理。量能仅在历史同时间样本足够且口径可比时作辅助，不设未经验证的固定阈值。回到区间内可作为候选失效的观察条件，但不等于已证明反向趋势；量能缺失或基线不足时只描述价格。
4. **结构解释**：三根局部转折只作观察，不等同完整缠论分型、笔、线段、中枢或买卖点。可提出多种波浪划分，并明确起止、反例与失效条件；缺少数据时不编号。Wyckoff 可讨论量价与供需假设，不可声称识别真实机构意图。这些理论和阈值尚未证明预测有效。
5. **事件与龙虎榜**：报道主张须标来源及发布时间、首次采集时间，影响是待证实假设；龙虎榜是盘后且特定席位信息。没有证据的传导路径写未知。
6. **输出**：分别列支持与不支持证据，给出上涨、震荡、下跌或证据不足的条件及失效点；不虚构胜率或成交能力。历史外样本验证之前不得宣称有效性。持仓和可成交性未知时等待，不自动交易。


## 理论方法：固定步骤、竞争解释与失效条件

以下是研究规则，不是已验证的预测模型。先标明时间周期、截至时间、数据质量，再给出证据与反证；不同周期和同一行情派生的指标不是独立证据。条件满足只支持某种解释，不保证后续收益。每种方法只在输入足够时适用；缺少原始K线、关键价格或必要历史数据时写“无法判定”，禁止补造。

### 一、道氏趋势与多周期结构

- 数据：日线、60分钟、15分钟已闭合K线，时间可比的高低点、收盘价、均线与收益。通过 bars 命令检查原始价格，不能只看汇总标签；遇除权、停牌或缺口先核对。
- 方法：先在日线记录最近两个可确认的高点与低点及时间，再看60分钟、15分钟是否同向。高点和低点依次抬高可作为上升结构候选，二者依次降低为下降结构候选，交叉或重叠则为震荡或未定。高低点的选取窗口与确认时间需说明；单次创新高不足以确认趋势。
- 支持：价格突破既有区间并在后续闭合K线上保持，且较大周期及板块表现未明显背离。反例：突破后快速回到区间、成交支持不足，或大级别下跌中的短线反弹。
- 失效：后续收盘跌破事先标注的最近确认调整低点，或突破后收回原区间；具体阈值和时间周期按当时已观察到的价格说明。没有可确认的转折序列时不要强行分类。

### 二、缠论：结构化观察，不冒充完整实现

- 数据：同一周期足够长且已闭合的原始高低开收K线；需另有明确的包含关系处理、分型、笔、线段、中枢的定义及版本，才能讨论对应严格结构。当前程序的三根局部转折未处理完整包含关系，也不提供已确认的笔、线段或中枢。
- 方法：先核对数据与调整口径，再逐项列出当前程序给出的局部高低点、确认时间和价格重叠区间；这些只能称为参考转折和观察区间。若人工依据原始K线探索更严格结构，必须说明采用的定义、包含处理、起止、确认时点及不确定性；结构尚未满足定义时标记候选或无法判定。
- 支持/反例：离开观察区间后，后续收盘持续位于区间外可支持突破延续假设；重新进入区间、关键转折被破坏或板块未跟随则削弱。不得仅凭MACD或量能减弱认定结构性背驰，也不能仅凭突破和回抽宣称一买、二买或三买。
- 失效：预先写出具体区间边界、确认周期与观察何时收回区间；新K线出现后可修正候选，不能把事后确定的分型当成先前已知。

### 三、艾略特波浪：至少保留替代路径

- 数据：多个周期、可确认的主要高低点、时间及波段涨跌幅；样本太短、复权口径不一致或结构不清时不编号。
- 方法：先固定所讨论的起点、终点和周期，再提出至少两条候选，例如上涨推动延续与更大下跌中的修正反弹；逐条说明关键高低点、支持证据及后续需要观察的动作。比例仅为辅助观察，不作为强制目标价。
- 支持/反例：前高突破并保持可支持延续候选；前高受阻、跌破已确认调整低点或大周期反向可支持修正候选。相同价格路径可以有不同划分，不以主观浪号替代事实。
- 失效：列出每条候选赖以成立的具体高低点和确认周期；边界被破坏则撤销或重划，并说明是哪一项新证据改变判断。

### 四、Wyckoff 与量价：投入和结果

- 数据：已闭合K线、前序区间高低、成交额及同时间历史基线和样本数；不同来源或样本不足时不比较。
- 方法：比较区间内外的价格推进幅度、成交额变化、突破后的保持或回归，以及回调时价格与成交变化。放量但价格推进有限可提出卖压或高换手等多种解释；缩量回调也可能源于买盘不足。
- 支持/反例：区间外闭合并保持、成交活动相对可比基线增加，可支持突破假设；重新回区间、同周期板块转弱或量能基线不足则削弱。无法凭公开K线识别机构真实吸筹或派发。
- 失效：约定区间边界、后续闭合周期和重新入区的判定；事件冲击、涨跌停约束或除权可能使历史量价关系失效。

### 五、A股情绪、板块轮动与个股地位

- 数据：三大指数、板块级行情榜单的实际采集时间、覆盖及口径、目标板块K线、成分股快照上涨比例、有效样本数及目标股与板块时间对齐的收益差；未提供的数据保持未知。
- 方法：先观察市场方向，再观察榜单中的候选板块及其时点，最后比较目标股和所属板块。仅有单次榜单只能描述当时排名；只有具备同来源、同分类、同口径且不同时间的有效快照，才能讨论排名或广度变化。板块分类和成分可能重叠。
- 支持/反例：板块相对市场走强、广度较高且个股相对板块表现同步可支持共振假设；少数权重股推动、广度不足、股板时间不一致或前期领涨股转弱是反例。无法从榜单直接得出主力资金流入或完整市场覆盖。
- 失效：写明相对收益转弱、广度下降或关键板块价格区间被破坏等可观察条件；没有可比历史快照时不声称扩散、退潮或持续性。

### 六、事件传导与对照验证

- 数据：报道链接、来源、发布时间、首次采集时间、相关股票/板块暴露依据及可观察的行情；标题与模型摘要均仅是待核实报道主张。
- 方法：分别写明已核实事实、未核实主张、潜在传导机制、影响对象和时间尺度，并查找能支持或反驳传导的可观察数据；未提供业务暴露或原文时标记未知。同源转载不视为独立确认。
- 失效：公告或原始来源否认、关键假设不成立、事件影响已被市场消化或行情未表现出预期反应，均可削弱假设，但短期未反应不单独证明事件无影响。
- 输出应至少比较上涨延续、区间震荡和下跌风险（数据不足时允许无法判断），每项列数据依据、关键价位、触发条件和反证；不生成未校准概率。交易约束未知时等待，15分钟方向判断不是可交易收益。

# Agent 证据加工：数值不等于证据，文字不等于预测

## 分层和入口

```text
采集适配器 → SQLite 原始记录／修订 → 统一可用截止与价格口径检查
          → research_batch 合格计算快照 → agent_evidence 确定性语义加工
          → 带编号的文字证据简报 → Claude 综合判断 → 最短最终报告
```

不是把 JSON 转义成字符串，也不需要另一次模型调用来翻译数据。Python
负责可重复计算、资格检查、空值原因与观察归纳；模型负责反证、事件传导与
最终方向。不能把“先算出一个 BULLISH”作为减少模型阅读量的捷径。

- `research` 默认输出文字简报；`--format json` 保留机器快照；`--pretty`
  隐含 JSON（旧用法兼容）。其他 context、bars 等入口仍按原契约输出 JSON。
- 显式 `stock_agent.py run` 复用相同快照和加工层；不完整时不调用模型。
  子进程只接收简报及固定决策标识，不把底层 context JSON 拼进提示词。
  返回的决策 JSON 和 WAIT 限制不变；本地 context 保留实际输入简报供审计。
- 本层不联网、不核验公告、不启动模型，不新增自动运行、交易或报告保存。

## 加工顺序与状态

| 输入情况 | 加工行为 | 不允许的解释 |
| --- | --- | --- |
| 合格且非空 | 标单位、实际周期、行情结束和采集时间，生成可引用事实 | 采集时间冒充报价时间 |
| 有效零值 | 保留 0.00%；成交额比零且有正基准样本则保留零倍 | 将零改为“未知” |
| 部分指标为空 | 保留其他有效项，说明样本不足／口径未核验等原因 | 填零、插值、绕过置空重新计算 |
| 非有限数、布尔或数字字符串 | 不强制转换为事实；可选指标局部停用 | NaN／Infinity 进入收益或标签 |
| 非正价格、少于三根、无资格状态、无时区／未来时点、采集早于 K 线结束 | 序列不可用、整轮 incomplete；仍可展示明确标记的历史参考价 | 用旧值冒充当前信号 |
| 过期、采集失败、重复结束时间 | 尊重上游 reference_only 与 error；停用当前组合观察、相对表现和结构条件 | 最近采集时间“洗新”旧 K 线或任意挑价 |
| 股板指结束时点不同 | 不输出该基准的相对领先／落后 | 强行比较最新值 |
| 大但有效的单根收益 | 绝对值≥8%时提示复核原始 K 线，不删值、不缩尾 | 直接判为坏数据、涨跌停、除权或机构意图 |
| 无新闻候选／未匹配龙虎榜 | 仅陈述已采集范围无候选／无匹配 | 证明不存在事件或官方未上榜 |
| 无榜单／全同值／最近失败／超龄待核对 | 不输出当前热点排名推断 | 对全零列表按代码生成名次 |
| 海外源未核验 | 日韩明确未知 | 用网页旧值补造当前报价 |

8%只是代码中显式的复核启发值 `LARGE_BAR_MOVE_PCT`，不校准方向，不是交易所
涨跌停规则，也不是丢弃数据的边界。源数据 OHLCV 合法性仍由采集适配器检查；
加工层不重新发明停牌、交易日历或公司行为信息。

数据状态沿用 ready／limited／incomplete，并叠加工层自身检查。新增硬异常
可使文字模式退出 1；可选指标异常只降级该项。JSON 模式保留原快照契约，
不把文字加工结果冒充采集状态。未知 issue code 仍展示，error 不会降成成功。

## 确定性计算观察

- 本根收益：已合格的 `close_t / close_t-1 - 1`；近四根收益使用五个价格点，
  **不是**当日涨跌幅。相对昨收另需完整前一会话收盘与跨日口径资格。
- 5期均价偏离：`close / MA5 - 1`；均价窗口变化：`MA5 / previous_MA5 - 1`。
  上游分别检查均价和斜率窗口，值能保留不意味着斜率可用。
- 偏离、窗口变化、近四根收益全正／全负，只归纳为偏强／偏弱**观察**。
  任一缺失则“组合观察不足”；有零或正负不一致则“观察分歧”，不自动判震荡。
  三者全零时陈述零值，不推断未来一定横盘。没有概率或投票加权。
- 相对表现：股与基准最新同区间单根收益之差，单位为**百分点**；任何依赖
  不可用或结束时点不一致，就显示未知，不取旧值替补。
- 成交额比：本根成交额／历史同钟点成交额中位数；展示有效基准样本数，
  缺基准或口径被屏蔽则未知。零倍不等于缺失，小样本不宣称经过验证的确认。
- 结构价位只列合格前序区间和最多两个已确认局部点，不自动生成买卖条件。
  局部点的三根内部同口径仍不保证能与今日价格比较；跨日点在整个历史
  窗口无核验覆盖时不作为当前确认／失效位，宁可少给，也不拼接未知口径。

## 证据组织和追溯

- 市场 `M:`、板块 `B:`、广度 `G:`、股票周期 `S:`、日内比较 `D:`、结构 `L:`、
  相对表现 `R:`、龙虎榜 `H:`、榜单 `K:`；事件保留真实 `evt_...` 标识。
  相同股板指和事件只展示一次。编号只定位本轮证据，不增加其可信程度。
- 简报先说明截面交易状态和研究口径：非交易时段仅作结构评价，下一交易时段方向需新证据；历史回放不是当前预测。采集计数属于本次调用，零次不认证原采集成功；逐项状态保留在同次快照 `acquisition.results`，可选 `--snapshot-out` 留存，不另起研究重取。
- 价位区分区间、已确认参考转折和单根参考，不自动把末根高低价升级为结构位；突破确认与候选否定用同一边界，不自动推导反向。日内回升不等于已确认多日修复。
- 每个价格序列保留实际 bar_end、captured_at、source；信息截止、生成时间和
  共同闭合时点分开显示。历史回放只读取当时已可用记录，不因翻译而补未来数据。
- 外部标题、来源、错误消息限制长度，压为单行并移除控制字符／伪造的方括号；
  仍视为不可信数据，这不是能消除语义提示注入的安全保证。
- 事件候选注明报道时间和首次采集时间，原文与财务影响不由本层背书。
  截断明确告知；需要完整 URL、正文、席位或更多历史时，使用同一信息截止的
  `context`／`bars` 深入，不把整个原始 JSON 再注入模型。
- 不注入上轮模型的长 reasoning，避免递归累积与当作新证据；交互模式沿用
  会话有效判断，显式编排模式必要时查看本地历史记录。

## 真实数据回归

`tests/fixtures/` 保存 2026-11-11 的历史采集截面（不是当前报价）：
两股 13:50 信息截止／13:45 K 线，以及襄阳轴承 10:45 的 +9.503916% 单根变化。
覆盖有效零值、跨日停用、小时线滞后、旧报道新采集、龙虎榜无匹配及大波动。
测试在副本上注入空值、非有限数、未来时点、过期和控制字符，不修改生产数据。
这些回归验证的是加工语义，不是方向预测准确率。自动编排输入使用模拟模型
验证，不为检查格式而额外执行付费模型调用。
